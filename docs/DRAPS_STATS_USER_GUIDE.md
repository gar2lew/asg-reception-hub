# DRAPS Stats — Reception User Guide

> ASG Reception Hub  
> For reception staff — plain English, step by step.

---

## 1. Opening DRAPS & Stats

Log in using your four-digit PIN.  Once the Dashboard loads, click
**DRAPS & Stats** in the sidebar.

![Sidebar navigation — DRAPS & Stats is under Workspace]

---

## 2. Choosing the reporting date

The page opens to today's date automatically.  Use the date picker at
the top to select a different date if you need to enter or review
results for a past day.

Dates are shown in Australian format: **dd/mm/yyyy** (e.g.
05/08/2026).

---

## 3. Selecting Brisbane, Perth, or All

Use the Office dropdown next to the date picker:

- **All Offices** — shows representatives assigned to Brisbane, Perth,
  and All Offices.
- **Brisbane** — shows only Brisbane representatives.
- **Perth** — shows only Perth representatives.

Choose the office you are currently reporting for.  The same report
date can have separate reports for each office.

---

## 4. Adding a representative

Open **Representatives** from the sidebar and click **Add
Representative**.

| Field | What to enter |
|---|---|
| Full Name | The rep's full name as it should appear in reports |
| Office | Brisbane, Perth, or All Offices |
| Daily DRAPS | Tick if this rep submits Daily DRAPS figures |
| First Consult | Tick if this rep does First Consult appointments |
| Finance Run | Tick if this rep does Finance Run appointments |
| Notes | Optional — any notes about this rep |

Click **Save**.  The new rep appears in the active list.

---

## 5. Editing or deactivating a representative

- Click the pencil icon to edit a rep's name, office, or inclusion
  settings.
- Click the archive icon to deactivate a rep.  They move to the
  Inactive list and can be restored later.
- Use the up/down arrows to reorder the list.

---

## 6. Entering Daily DRAPS

1. On the DRAPS & Stats page, expand the representative's card.
2. In the **Daily DRAPS** section, set the status to **Figures
   Supplied**.
3. Enter the numbers:

| Field | What to enter |
|---|---|
| Door Q | Number of door questionnaires taken |
| Referrals | Number of referrals received |
| Appointments | Number of appointments booked |
| Presented | Number of presentations done |
| Sold | Number of sales closed |

All numbers must be whole numbers (no decimals).  Leave a field blank
if you do not have the figure yet.

---

## 7. Entering First Consult results

1. In the **First Consult** section, set the status to **Figures
   Supplied**.
2. Enter:

| Field | What to enter |
|---|---|
| Booked | Number of first-consult appointments |
| Presented | Number of first-consult presentations |
| Sold | Number of first-consult sales |

---

## 8. Entering Finance Run results

Same as First Consult, in the **Finance Run** section.

---

## 9. Using Not Supplied by Rep

If a representative did not provide their figures for a particular
section:

1. Set that section's status to **Not Supplied by Rep**.
2. All fields will display `/` and cannot be edited.
3. The section is excluded from the day's totals.
4. It will appear in the missing-submission summary.

---

## 10. Using Not Applicable Today

If a section does not apply today (for example, no Finance Run
appointments were scheduled):

1. Set the status to **Not Applicable Today**.
2. All fields display `N/A`.
3. The section is excluded from totals and is not counted as missing.

---

## 11. Using Observation

If a rep's figures are based on observation rather than formal
reporting:

1. Set the status to **Observation**.
2. The section is labelled Observation.
3. Enter the figures you have.
4. The figures count toward the day's totals, but the report clearly
   marks the section as observational.

---

## 12. Saving a draft

Click **Save Draft** to save all your entries without completing the
report.  You (or another receptionist) can return later to finish.

- A green "Draft saved" message appears when successful.
- The last-saved time is shown near the top.
- If saving fails, a red error message appears and your entries are
  preserved.

---

## 13. Completing a report

When all representatives have been entered:

1. Click **Mark Complete**.
2. If any sections are incomplete, a message tells you which reps and
   sections need attention.
3. If everything is complete, confirm the prompt.
4. The report status changes to Complete and records who completed it
   and when.

---

## 14. Correcting a completed report

1. Open **Previous Reports** from the DRAPS page (or sidebar).
2. Find the report and click the edit (reopen) icon.
3. Confirm the prompt.
4. The report returns to Draft status.  Make your changes and click
   **Mark Complete** again.

---

## 15. Opening previous reports

Click **Previous Reports** on the DRAPS page or navigate from the
sidebar.  Reports are sorted newest-first.  Use the Office and Status
filters to narrow the list.

---

## 16. Printing the report

From the Previous Reports list, click the printer icon next to any
report.  This opens a clean printable view.

Use **Ctrl+P** (or File → Print) to print.  The printout includes ASG
branding, all rep figures, totals, conversion rates, and a summary.

---

## 17. Downloading the PDF

From the print view, use **Ctrl+P** and select **Save as PDF** as the
printer destination.  The suggested filename is:

`Daily_DRAPS_DD-MM-YYYY.pdf`

---

## 18. Using the report to update the spreadsheet

After printing or saving the PDF:

1. Open the official DRAPS spreadsheet.
2. Locate the matching date and office tab.
3. Copy the figures from the printed report into the spreadsheet.
4. Use the totals row and conversion rates in the report to verify your
   spreadsheet entries match.

The app does not automatically update the spreadsheet — you transfer the
figures yourself.

---

## 19. What to do when figures are missing

- If a rep has not yet submitted: use **Not Supplied by Rep**.
- If a section does not apply: use **Not Applicable Today**.
- If you only have partial figures: enter what you have and mark as
  Observation, or leave the report as Draft until the figures arrive.

Never enter made-up numbers.  Missing data should be clearly marked so
the manager can follow up.

---

## 20. Common mistakes to avoid

- **Saving without completing**:  Remember to click **Save Draft**
  regularly — your entries are not saved automatically.
- **Leaving blanks in Figures Supplied**:  If a rep supplied figures
  but one field is genuinely zero, enter `0`.  Do not leave it blank.
- **Using the wrong office filter**:  Check that you are viewing the
  correct office before entering figures.
- **Forgetting to reopen a completed report**:  Completed reports must
  be reopened before editing — click the edit icon on the Previous
  Reports page.
- **Entering decimal values**:  All fields accept whole numbers only.
  `2.5` will not be accepted.
- **Entering negative numbers**:  Negative values are rejected.
